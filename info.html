01

Executive Summary

ПУЛЬС — первая в России платформа, объединяющая персональное медицинское хранилище, ИИ-ассистента здоровья и маркетплейс медицинских услуг в одном продукте. Пациент видит всю хронологию своего здоровья, получает понятные объяснения анализов, одним QR-кодом открывает доступ любому врачу и сразу находит лучшие цены на лекарства и анализы рядом с домом.

Текущие игроки (Яндекс.Здоровье, СберЗдоровье, ЕМИАС) решают только один аспект: запись к врачу ИЛИ агрегация лабораторий ИЛИ государственная карта. Никто не объединил всё это в одном пациент-ориентированном продукте. ПУЛЬС занимает эту незакрытую нишу.

Проблема
Данные о здоровье разбросаны по десяткам клиник, приложений и бумажных карт. Ни пациент, ни врач не видят полную картину.
Решение
Единое хранилище + ИИ + маркетплейс. Пациент управляет своими данными. Врач получает полный контекст. Клиника монетизируется через платформу.
Бизнес-модель
Комиссия с маркетплейса (лекарства, анализы, запись к врачу) + B2B подписка + Premium B2C + обезличенные датасеты.
Конкурентный ров
Накопленные данные пациентов создают сетевой эффект. Чем больше данных — тем умнее ИИ, тем ценнее продукт для всех участников.

04

Концепция продукта

01 · Хранилище данных на всю жизнь
Анализы, снимки, выписки, прививки, рецепты — всё с рождения в одном месте. Частные и государственные клиники, умные часы (Apple Health, Google Fit, Garmin), загрузка PDF/фото через OCR. Отдельные профили для каждого члена семьи.
02 · ИИ-ассистент здоровья
Переводит медицинский язык на простой. Отслеживает динамику ключевых показателей (гемоглобин, сахар, холестерин, ферритин). Напоминает когда записаться к врачу. Multi-model верификация: несколько ИИ перепроверяют ответ — снижение галлюцинаций. RAG на базе медицинских исследований.
03 · QR-доступ для врача
Пациент показывает QR-код — врач из любой клиники открывает полную историю в браузере без установки приложения. Режимы: временный (один визит), постоянный (лечащий врач), выборочный (только часть данных, например только анализы крови). Клиника покупает B2B-подписку для постоянного доступа.
04 · Маркетплейс после приёма
Выписка врача → лучшие цены на лекарства в ближайших аптеках. Назначены анализы → лаборатории рядом с ценами. Запись к следующему врачу по рейтингу и отзывам. Геолокация для поиска рядом.
05 · Геймификация и удержание
Счётчик «продления жизни»: прошёл 10K шагов → +5 дней к прогнозу. Выполнил назначения → бонус. Партнёрская программа: скидки в аптеках за активность. Приложение мотивирует открывать его ежедневно — это критично для retention.

User Stories

Формат: Как [роль], я хочу [действие], чтобы [ценность]. Приоритет по MoSCoW.

Пациент (B2C)

US-001Must HaveХранилище
Как пациент, я хочу видеть все свои анализы в хронологическом порядке, чтобы отслеживать динамику показателей здоровья.
Критерии приёмки: список анализов с датой и источником; фильтрация по типу (кровь, мочи, гормоны); график динамики ключевых показателей; цветовая индикация отклонений от нормы.
US-002Must HaveХранилище
Как пациент, я хочу загрузить PDF или фото результата анализа, чтобы он хранился в единой системе и был структурирован.
Критерии приёмки: OCR распознаёт бланк; извлекает числовые показатели и единицы измерения; привязывает к дате; показывает источник «загружено вручную».
US-003Must HaveИИ
Как пациент, я хочу получить объяснение результата анализа простым языком, чтобы понять что делать дальше.
Критерии приёмки: ИИ объясняет каждый показатель с отклонением; указывает нормальный диапазон; даёт рекомендацию («стоит обсудить с терапевтом»); не ставит диагноз; содержит disclaimer.
US-004Must HaveДоступ
Как пациент, я хочу показать QR-код врачу для быстрого доступа к моей карте, чтобы не пересказывать историю болезни устно.
Критерии приёмки: QR генерируется в 1 клик; врач открывает в браузере без регистрации; отображается полная история; доступ истекает через заданное время (1ч / 24ч / постоянный); лог: кто и когда открывал.
US-005Must HaveМаркетплейс
Как пациент после приёма, я хочу видеть цены на назначенные лекарства в ближайших аптеках, чтобы купить выгодно.
Критерии приёмки: список лекарств из выписки; цены из 3+ аптечных сетей; сортировка по цене и расстоянию; навигация к выбранной аптеке.
US-006Should HaveХранилище
Как пациент, я хочу чтобы умные часы автоматически синхронизировали данные (пульс, шаги, сон) в мою карту.
Критерии приёмки: поддержка Apple Health и Google Fit; синхронизация 1 раз в день; данные отображаются в дашборде; пользователь может выбрать какие данные синхронизировать.
US-007Should HaveИИ
Как пациент, я хочу получать умные уведомления когда стоит записаться к врачу, чтобы не пропускать важные обследования.
Критерии приёмки: напоминания на основе дат предыдущих визитов; уведомление при аномальных тенденциях в анализах; ежегодные напоминания о профилактических обследованиях по полу и возрасту.

Врач (B2B-инструмент)

US-008Must HaveДоступ
Как врач, я хочу отсканировать QR пациента и увидеть всю историю болезни, чтобы поставить более точный диагноз.
Критерии приёмки: открывается менее чем за 3 секунды в любом браузере; структурированная история: анализы, диагнозы, препараты, аллергии; хронологическая лента; экспорт в PDF.
US-009Should HaveИИ
Как врач, я хочу получать ИИ-подсказки во время приёма на основе истории пациента, чтобы не пропустить важные взаимосвязи.
Критерии приёмки: ИИ анализирует симптомы + историю; предлагает диагностические гипотезы с вероятностью; указывает на потенциальные взаимодействия препаратов; ссылается на источники (PubMed / КлинРек).

Клиника (B2B API)

US-010Should HaveAPI
Как клиника, я хочу интегрироваться через REST API для автоматической передачи результатов анализов пациентам, чтобы не просить их скачивать PDF вручную.
Критерии приёмки: REST API с авторизацией (OAuth2); webhook для уведомлений; документация (Swagger); тестовая среда; SLA 99.9%.

Монетизация

💊
01 · Комиссия: маркетплейс лекарств
Агрегация цен из аптечных сетей (Apteka.ru, Еаптека, сети). После выписки рецепта — мгновенная конверсия. Пациент уже в контексте «купить».
10–15% комиссия · потенциал ₽2–5B/год при 500K MAU
Высокий
🧪
02 · Комиссия: агрегатор лабораторий
Запись на анализы через лаборатории-партнёры (Helix, Invitro, CMD). Доказанная бизнес-модель — этот рынок уже монетизируется. Мы приходим с трафиком.
10–20% комиссия · сред. чек ₽2 000 → ₽200–400 с заказа
Высокий
📅
03 · Комиссия: запись к врачу
Онлайн-запись в клиники через маркетплейс. Клиники платят за привлечённого пациента (CPA) или по подписке за доступ к аудитории.
₽300–800 / визит · B2B подписка ₽15K–50K/мес/клиника
Средний
👨‍⚕️
04 · Подписка врача / клиники
Расширенный портал врача: ИИ-подсказки в режиме приёма, история пациентов, аналитика. Клиники платят как за SaaS-инструмент для своей команды.
₽500–2 000/мес на врача · SaaS клиники ₽10K–30K/мес
Средний
⭐
05 · Premium подписка (B2C)
Freemium модель. Бесплатно: хранилище 50 записей + базовый ИИ. Premium: безлимит + расширенный ИИ + семейный план + приоритетный доступ.
₽199–499/мес · ₽1 990–4 990/год
Рост
🧠
06 · Обезличенные датасеты
Анонимизированные паттерны заболеваний для фармкомпаний и разработчиков медицинских ИИ. Требует согласия пользователей и соответствия 152-ФЗ. Фармкомпании платят хорошо.
B2B контракты ₽5M–50M · долгосрочная история
Будущее
📢
07 · Нативная реклама
Только контекстно-релевантная реклама: после диагноза «показаны санатории», после анализа щитовидки — специализированные клиники. Никакого баннерного спама.
CPM модель · доп. доход при 100K+ MAU

Маркетинговая стратегия (Phase 1–2)

Врачи-блогеры

Пилот с клиниками
Клиника даёт ПУЛЬС своим пациентам — instant нативная установка без рекламы.
SEO / органика
"Как расшифровать анализ крови" — миллионы запросов. ИИ-объяснения = SEO-машина.
Гранты Минздрава / Сколково
Цифровизация здравоохранения = приоритет государства. Гранты до ₽20M без разводнения.
