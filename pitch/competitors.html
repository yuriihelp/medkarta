💡 Стратегические выводы
🎯

Незанятая ниша #1 — Агрегация лабораторий

Инвитро, Гемотест, KDL, CMD — каждый в своём силосе. Пациент с анализами из 3 лаборатории открывает 3 приложения. ПУЛЬС единственный собирает всё в одном месте с ИИ-анализом динамики.

👩

Незанятая ниша #2 — Женское здоровье + PHR

Ни один прямой конкурент не объединяет: менструальный календарь + трекинг беременности + история анализов + ИИ-ассистент. 54% аудитории рынка — женщины, это недообслуженный сегмент.

🔗

Незанятая ниша #3 — Ссылка для врача

Ни один конкурент не даёт пациенту сгенерировать ссылку с данными для врача без регистрации. Это viral loop: врач видит удобный интерфейс → советует пациентам → органический рост.

⚡

Главный риск — Яндекс или Сбер

Оба могут добавить PHR-модуль за 6–12 месяцев. Защита: быть быстрее, накопить данные пользователей, выстроить B2B (клиники), получить лицензию МИС. Данные — главный ров.

🏛

Долгосрочный риск — ЕГИСЗ

Государство через 3–5 лет может обязать все клиники интегрироваться с ЕГИСЗ, создав де-факто гос. монополию. Стратегия: стать приложением поверх ЕГИСЗ (как приложение над гос. данными).

🔬

Партнёрская возможность — МИС клиник

Medods, Infoclinica, 1С:Медицина обслуживают тысячи клиник. Интеграция через API → данные пациентов автоматически попадают в ПУЛЬС. B2B2C-стратегия роста без прямых маркетинговых затрат.
