Данные разбросаны по клиникам

Анализы из ЛИС, снимки из PACS, справки на бумаге — у каждого врача только его часть истории. Пациент не видит полной картины.

🔄

Нет преемственности лечения

При переходе между клиниками или регионами история болезни теряется. Врачи назначают одни и те же анализы повторно.

🧠
